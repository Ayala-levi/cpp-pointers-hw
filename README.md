# שיעורי בית - מצביעים גנריים ומצביעים לפונקציות ב-C++

## תיאור

פרויקט זה מכיל את פתרונות שיעורי הבית שלי בנושא מצביעים גנריים (`void*`) ומצביעים לפונקציות בשפת התכנות C++. הקוד מדגים שימושים שונים של מושגים אלה, כפי שהוצגו בדף העבודה המצורף.

## תוכן הפרויקט

הפרויקט כולל את הקבצים הבאים:

* **source.cpp** - קובץ קוד המקור ב-C++ המכיל את הפתרונות לתרגילים השונים.
* **README.md** - קובץ זה, המספק סקירה כללית של הפרויקט.
* **מצביע גנרי ומצביעים לפונקציות** - עותק דיגיטלי של דף העבודה.

## הסברים ותכונות עיקריות

הקוד מדגים את הנושאים הבאים:

* **מצביעים גנריים (`void*`)**: שימוש במצביעים שיכולים להצביע על כל סוג נתונים, כולל הדגמה של פונקציית `swap_any` להחלפת ערכים בין שני משתנים ללא תלות בסוגם.
* **מצביעים לפונקציות**: שימוש במצביעים כדי לאחסן את הכתובות של פונקציות ולהפעיל אותן דרך המצביע. הפרויקט כולל דוגמאות של פונקציות עם חתימות שונות ושימוש במצביעים כדי להצביע עליהן.
* **מערך של מצביעים לפונקציות**: הדגמה של יצירת מערך המכיל מצביעים לפונקציות והפעלת פונקציה מתוך המערך בהתאם לקלט.
* **פונקציות השוואה באמצעות מצביעים לפונקציות**: שימוש במצביעים לפונקציות כדי להעביר פונקציות השוואה שונות (כגון השוואה לפי שכר או לפי שם) לפונקציה אחרת (לדוגמה, פונקציית מיון, אם כי היא לא מיושמת במלואה בקוד).
